# NGAFID 航空维修事件二分类检测

## 📖 项目背景
本项目基于论文 *"A Large-Scale Annotated Multivariate Time Series Aviation Maintenance Dataset from the NGAFID"*。
核心任务是利用 NGAFID 提供的航空多元时间序列数据，完成**维修事件的二分类检测**（即区分飞机在“维修前”和“维修后”的飞行数据）。本项目在复现基准代码的基础上，实现了模型的优化与 5 折交叉验证（5-Fold Cross-Validation）。

## 🗂️ 数据集说明
本项目使用的数据集包含两部分：
1. **原始飞行数据**：通过 Zenodo 获取的原始 CSV 文件。(https://doi.org/10.5281/zenodo.6624956)
2. **基准标签数据**：包含 19 种维修事件的基准数据子集（Benchmark Subset）。

> **注**：因数据量较大，本项目仓库不包含原始数据集。请在运行代码前，确保已正确下载并配置好数据路径。

## 🛠️ 环境依赖与运行方式
本项目代码已在 **Google Colab** 环境下测试通过，主要依赖以下 Python 库：
* `pandas` / `numpy` (数据处理)
* `scikit-learn` (机器学习与交叉验证)
* `matplotlib` (数据可视化)

**运行步骤：**
1. 克隆本仓库到本地或直接在 Google Colab 中打开 `.ipynb` 笔记本文件。
2. 配置数据集路径（如果你使用 Google Drive，请确保已挂载云盘并修改代码中的读取路径）。
3. 依次运行代码块，完成数据预处理、模型训练与评估。

## 📊 实验结果 (五折交叉验证)
为验证复现效果，本项目在 19 个航空维修事件子集上分别运行了 **MiniRocket**、**ConvMHSA** 和 **InceptionTime** 三种模型，并严格采用 5 折交叉验证（5-Fold CV）统计平均准确率（Mean Accuracy）。

|   **Fold 1**   |        0.4615       |        0.5233       |        0.5094       |
|   **Fold 2**   |        0.5288       |        0.5119       |        0.4920       |

## 🔍 结果分析
1. **复现一致性**：除硬件导致的训练不充分外，其余细微差异可能源于随机种子的设置，或是数据预处理（如归一化、重采样逻辑）的微调。尽管如此，MiniRocket 模型依然在极短的时间内展现出了与基准接近的分类能力。
2. **性能表现**：在本项目实验中，[此处填入：XX 模型] 表现最优，证明了其在处理航空多元时间序列数据上的优势。
3. **硬件限制与参数妥协**：限于电脑硬件（如 Colab 免费版分配的显存）限制，在训练参数量较大的深度学习模型时，总是频繁发生 `ResourceExhaustedError: Out of memory (OOM)`。考虑到本次复现的首要目的是为了**测试基准代码的可用性**，验证模型流程是否能彻底跑通，故在实验中选择继续缩小了 `batch_size` 与 `epochs`。这也是导致本项目复现准确率（Mean Acc）相比原论文极限性能存在一定差距的主要原因。
4. **未来展望 (Future Work)**
* **特征工程优化**：进一步挖掘 NGAFID 数据的物理特性（如姿态角、发动机参数间的关联性），通过特征选择降低数据维度，从根本上缓解内存压力。
* **算力升级与全量训练**：在未来获取更充沛的 GPU 算力支持后，恢复原论文设定的 `batch_size` 与 `epochs` 进行全量训练，以探寻这些模型在航空数据集上的真实性能上限。
* **实时性研究**：将目前的离线二分类检测扩展为实时流数据检测，模拟实际飞行过程中的实时健康监控。
